JobMatcher is model-agnostic: bring your own API key, or point it at a local model. Requests go directly from your browser to the endpoint below — there is no middleman server.

Ollama note: Ollama rejects browser extensions by default. On macOS run launchctl setenv OLLAMA_ORIGINS "chrome-extension://*" in Terminal, then quit and reopen Ollama (Linux/Windows: set the OLLAMA_ORIGINS=chrome-extension://* environment variable for the Ollama service).
